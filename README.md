# 🎓 UniGuide AI

UniGuide AI is an AI-powered student guidance platform designed to help students discover academic opportunities, internships, hackathons, and career resources in one place.

## 🚀 Features

* 🤖 AI-powered student assistance
* 📰 Latest IT and technology news
* 💼 Internship opportunities
* 🏆 Hackathon discovery platform
* 🔐 Secure authentication system
* 👤 User profile management
* 📱 Responsive and modern user interface

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* HTML5
* CSS3
* JavaScript

### Backend

* Django
* Django REST Framework
* Python

### Authentication & APIs

* Google OAuth
* Gemini API

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/gillbert-joshua77/UniGuide-AI.git
```

### Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd Backend
pip install -r requirements.txt
python manage.py runserver
```
